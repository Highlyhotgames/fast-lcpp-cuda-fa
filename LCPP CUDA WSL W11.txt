Build llama-cpp from source with CUDA in WSL (W11) and Flash Attention

What we'll be using:
-> NVIDIA Driver v581.80
-> CUDA v13.0.2
-> WSL v2.6.2
-> Ubuntu v24.04
-> Python v3.14
-> flash-attention v2.8.3
-> llama-cpp b7285


W11 pre-requisites:
-> Run Windows Update before anything -> restart PC if needed
-> Latest NVIDIA driver -> restart PC if your driver was updated


Stage:

A)
-> Install WSL
-> Install Ubuntu distro
1. Start menu -> turn windows features on or off -> enable: Virtual Machine Platform; Windows Subsystem for Linux -> restart PC
2. Start menu -> Powershell (run as admin) -> "wsl --update" (in case it updates, restart pc and open PS again [admin]) -> "wsl --install Ubuntu-24.04" -> set a username and pass -> "exit" -> restart PC
3. Start menu -> WSL Settings -> Set "Memory Size" to be the same as your RAM (mine is 16GB, so 16 x 1024 = 16384MB) -> Close "WSL Settings" window
4. Open WSL Settings again -> confirm your Memory Size was automatically changed to a slightly lower value (if it didn't, restart PC again, mine has changed to 16099MB but can vary per system)
5. Make sure "Swap Size" is set to (equal or higher than) 8192MB
6. Run PS again as admin, run "wsl --shutdown"


B)
-> Disable WSL IPv6 support
-> Tune Linux swappiness
-> Install apt-fast

1. Start menu -> Command Prompt (to monitor C:)
2. 'while ($true) { Clear-Host; Get-CimInstance -ClassName Win32_LogicalDisk -Filter "DeviceID='C:'" | Select-Object DeviceID, VolumeName, @{Name='FreeSpace (GB)'; Expression={$_.FreeSpace / 1GB -as [int]}}, @{Name='Size (GB)'; Expression={$_.Size / 1GB -as [int]}}; Start-Sleep -Seconds 1 }'
3. Launch Ubuntu 24.04 (to monitor RAM/swap)
4. 'watch -d -n 1 "free -h | awk '{print \$1, \$2, \$3, \$4}' | column -t"'
5. Launch Ubuntu 24.04 (to install and run lcpp)
6. "sudo nano -w /etc/sysctl.conf"
7. Add these lines:
-----
# Disable IPv6
net.ipv6.conf.all.disable_ipv6=1
net.ipv6.conf.default.disable_ipv6=1
net.ipv6.conf.lo.disable_ipv6=1
-----
8. Save and exit ("Ctrl+X" -> "Y" -> Enter key)
